# ADR-0003: Originality policy (avoid IP / plagiarism claims)

- **Status:** Accepted — 2026-11-14

## Context
The game is inspired by the *geography detective chase* genre popular in the 1990s–2000s. Game mechanics and genres are not protected by copyright, but names, characters, story, artwork, music, text and trade dress are.

## Rules
1. No names, characters, organizations, catchphrases, logos, music, sound, art style or text from any existing game.
2. Original title, agency, villains, story and visual identity.
3. All clue text written from scratch using public geographic facts.
4. Only assets that are self-made or under CC0 / explicitly commercial-friendly licenses; every third-party asset is logged in `CREDITS.md` with its license.
5. Mechanics are reinterpreted, not copied screen by screen (e.g. 3D globe travel, deduction board, combo/time bonuses, rank progression).
