# Devlog — 2026-11-16 — Modern UI and action layer

Feedback: "the base idea is good but it lacks dynamics and action — show the thief escaping, make asking for clues interactive, and the UI should be modern (not futuristic/purple)". Overnight session.

## What changed
- **Design system** (`ui/style.gd`): light warm background, white rounded cards with soft shadows, coral accent, navy ink, sky/rose for where/who. Outfit + Inter + JetBrains Mono (OFL, variable fonts with explicit weights).
- **Interactive clues** (`ui/clue_reveal.gd`): wiretap tuning mini-game (fast = 1 h cheaper), CCTV scan & zoom, contact dialogue, flipping receipts, boss phone chat.
- **Cutscenes** (`ui/cutscene.gd`): a recurring thief (fedora, trench coat, coral scarf) drawn in code over per-city skylines — heist, plane, car, rooftop, arrest, safe house; looping hero banners on the cases/escapes screens.
- **Action events** (`ui/minigame.gd`): sightings (tap the suspect 3× → +3 h) and passport control (needle timing → −3 h on fail), scheduled deterministically per case and unit-tested.
- **Sound & music** (`tools/make_sfx.py`, `ui/sfx.gd`): 15 synthesized effects + a noir jazz loop, mute toggle.
- **Feedback**: flight preview arc, low-time warning, chase camera shake, route recap globe on results, board traits coloured ✓/✗ against known evidence, city banners use the city's own photo.
- **Street photos**: curated openly-licensed photos for (almost) every city — see `CREDITS.md`.

## Tooling
- `tests/screenshot_tour.gd` renders 35 screens under xvfb for visual QA; README screenshots come from it.
- `tests/smoke_ui.gd` drives overlays, cutscenes and mini-games in CI.
- 325 GDScript tests + UI smoke + 7 Python tests.

## Lessons
- Wikimedia throttles non-standard thumbnail widths; standard sizes and a descriptive User-Agent avoid most 429s.
- Variable fonts need the OpenType tag (`name_to_tag("wght")`) in Godot 4.4 to apply weights.
- Delayed callbacks should be tweens owned by the node they touch, so they die with it.
